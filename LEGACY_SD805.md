# Legacy sd805 v1.0

The old v1.0 Core Patch targeted the former `sd805/L4D2VR` codebase, specifically commit:

`628820257ae755ae120b8f86740a145b6fb74f51`

It used a modified/rebuilt `d3d9.dll` and is **not compatible with the current keyou91/L4D2VR approach**.

The obsolete binary package has been removed from the current branch to avoid accidental installation on the modern build.

If historical recovery is ever needed, it remains available in this repository's Git history before the v2.0 migration.

For current L4D2VR, use:

`L4D2VR_Y_Vocalizer_Current_v2.0.zip`

v2.0 is configuration-only: it uses native CustomAction support and does not replace the VR DLL.
