L4D2 VR - Y VOCALIZER UNIVERSAL

Universal Y-button vocalizer bridge for the sd805 version of L4D2VR.

SUPPORTED L4D2VR VERSION
This patch is designed specifically for:
https://github.com/sd805/l4d2vr

It was built for the sd805/L4D2VR codebase currently based on commit:
628820257ae755ae120b8f86740a145b6fb74f51

Other forks or modified L4D2VR builds may use a different d3d9.dll and are NOT guaranteed to be compatible.

WHAT IT DOES
The Y button opens the standard Left 4 Dead 2 radial menu named "Orders".

If you already use a standard vocalizer that replaces the Orders menu:
- Y opens YOUR installed vocalizer.
- Your language is preserved.
- Your own phrases and radial layout are preserved.

If you do not have a vocalizer installed:
- Y opens the normal Left 4 Dead 2 Orders radial menu.

This Workshop item does NOT replace radialmenu.txt and does NOT install its own vocalizer.

REQUIRED - Y BUTTON CORE PATCH
Download the Core Patch here:
https://github.com/Wokgui/L4D2VR-Y-Vocalizer-Universal-Core-Patch/raw/main/L4D2VR_Y_Vocalizer_Universal_Core_Patch_v1.0.zip

INSTALLATION
1. Install the sd805 version of L4D2VR.
2. Subscribe to this Workshop item.
3. Download the Core Patch using the link above.
4. Extract the ZIP.
5. Close Left 4 Dead 2 if it is running.
6. Double-click INSTALL_Y_VOCALIZER_UNIVERSAL.bat.
7. Start SteamVR and launch L4D2VR with -insecure.

The installer automatically detects Left 4 Dead 2 and backs up your existing L4D2VR d3d9.dll before replacing it.

UNINSTALL
Run UNINSTALL_Y_VOCALIZER_UNIVERSAL.bat.
The installer backup will be restored automatically.

COMPATIBILITY
- Designed for sd805/L4D2VR.
- Designed for standard L4D2 vocalizers that use or replace the Orders radial.
- Standard vocalizers keep their own language, phrases and layout.
- If no vocalizer is installed, the native L4D2 Orders menu is used.
- Vocalizers using completely custom radial names may require additional configuration.
- Other L4D2VR forks are not guaranteed to work.
