[h1]L4D2VR – Y BUTTON VOCALIZER SHORTCUT[/h1]

Adds a simple Y-button shortcut for your existing Left 4 Dead 2 vocalizer in the current L4D2VR build.

[h2]CURRENT VERSION[/h2]

Designed for the current L4D2VR project by keyou:

https://github.com/keyou91/l4d2vr

This replaces the old sd805-specific Core Patch.

[h2]WHAT IT DOES[/h2]

The current L4D2VR already supports configurable Custom Actions and held keyboard-key mappings.

This patch uses that native system to make the Quest/Oculus Touch [b]Y button behave like Ctrl[/b].

If Ctrl already opens your vocalizer:

[list]
[*] Hold Y → opens the same vocalizer.
[*] Use your normal VR pointing/shooting method to select a phrase.
[*] Release Y → releases Ctrl.
[/list]

[h2]IMPORTANT – NORMAL CONTROLS ARE NOT MODIFIED[/h2]

This v2.0 patch does [b]not[/b]:

[list]
[*] modify d3d9.dll;
[*] patch L4D2VR C++ code;
[*] replace radialmenu.txt;
[*] install its own vocalizer;
[*] use either thumbstick to navigate the vocalizer;
[*] modify movement or turning;
[*] modify trigger bindings;
[*] add a custom VR overlay/pointer system.
[/list]

The goal is deliberately simple: [b]Y is only a shortcut for the Ctrl key you already use for your vocalizer.[/b]

[h2]INSTALLATION[/h2]

[list=1]
[*] Install the current keyou91/L4D2VR build.
[*] Check that Ctrl already opens your vocalizer.
[*] Close Left 4 Dead 2.
[*] Close SteamVR.
[*] Download and extract the v2.0 ZIP.
[*] Run [b]INSTALL_Y_VOCALIZER_CURRENT.bat[/b].
[*] Restart SteamVR.
[*] Launch L4D2VR.
[/list]

The installer automatically detects Left 4 Dead 2 and backs up the L4D2VR files it changes.

[h2]HOW IT WORKS[/h2]

The installer uses a free L4D2VR CustomAction and configures it as:

[code]hold:key:ctrl[/code]

It then remaps only the physical Y button on Oculus/Quest Touch controllers to that CustomAction.

No gameplay-input code is replaced.

[h2]CONTROLS[/h2]

[b]Hold Y[/b]
Opens exactly the same vocalizer as Ctrl.

[b]Point / shoot[/b]
Use the same VR method you already use when the vocalizer is opened with Ctrl.

[b]Release Y[/b]
Releases Ctrl.

[b]Thumbsticks[/b]
Normal L4D2VR movement/turning. They are not used by this patch.

[h2]UNINSTALL[/h2]

Close L4D2 and SteamVR, then run:

[b]UNINSTALL_Y_VOCALIZER_CURRENT.bat[/b]

The original L4D2VR configuration and Oculus Touch binding are restored.

[h2]IF Y STILL OPENS PAUSE[/h2]

SteamVR may be using an old personal controller binding.

Reset the L4D2VR controller binding to the current/default binding, restart SteamVR and test again.
