L4D2VR sd805 - Y VOCALIZER + SANS RECENTRAGE v3.3
===================================================

Cette version est faite pour l'ancien L4D2VR sd805 v0.6.2, commit
628820257ae755ae120b8f86740a145b6fb74f51.
Elle n'utilise pas les CustomAction des versions keyou91 recentes.

Fonctionnement :
- appui sur Y : +mouse_menu Orders est envoye une seule fois ;
- Y maintenu : le vocalizer reste ouvert sans repeter la commande ;
- relachement de Y : la commande native -mouse_menu, sans argument, est envoyee une seule fois ;
- si le menu radial masque le relachement SteamVR, l'etat physique de Y ferme quand meme le menu ;
- Y utilise un ensemble d'actions SteamVR dedie, limite a la main gauche et
  prioritaire pendant l'interaction du radial ;
- clic du stick gauche : aucun recentrage ; le mouvement du stick reste normal.

Portee du patch :
- un ensemble SteamVR /actions/orders separe est ajoute ;
- seul Y dans le profil Oculus Touch / Quest est lie a /actions/orders/in/Hold ;
- le clic ResetPosition est retire uniquement du joystick gauche Oculus Touch ;
- Pause, Knuckles, Vive Cosmos, axes des sticks, gachettes, armes et bras VR restent inchanges ;
- radialmenu.txt et le contenu du vocalizer Orders ne sont pas remplaces.

Installation :
1. Fermer Left 4 Dead 2 et SteamVR.
2. Lancer INSTALL_Y_VOCALIZER_SD805.bat.
3. Redemarrer SteamVR.
4. Lancer L4D2VR.

Le programme sauvegarde le d3d9.dll, le manifeste SteamVR et le binding Oculus
avant installation dans :
VR\Wokgui_Y_Vocalizer_Backup_sd805_v3

Desinstallation :
Fermer le jeu et SteamVR puis lancer UNINSTALL_Y_VOCALIZER_SD805.bat.

Compilation : GitHub Actions, Release x86, MSVC v143. MinHook est reconstruit
avec le meme compilateur que le DLL pour eviter C1047 / LNK1257.
