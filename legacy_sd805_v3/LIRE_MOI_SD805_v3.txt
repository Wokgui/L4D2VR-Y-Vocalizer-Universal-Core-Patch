L4D2VR sd805 - Y VOCALIZER + SANS RECENTRAGE v3.4
===================================================

Cette version est faite pour l'ancien L4D2VR sd805 v0.6.2, commit
628820257ae755ae120b8f86740a145b6fb74f51.

Fonctionnement voulu :
- appui sur Y : le vocalizer Orders s'ouvre ;
- Y maintenu : le vocalizer reste ouvert ;
- controleur droit : selection dans le vocalizer comme dans la configuration fonctionnelle precedente ;
- relachement de Y : le vocalizer se ferme immediatement ;
- clic du stick gauche : aucun recentrage ;
- axe du stick gauche : mouvement conserve normalement.

Correction v3.4 :
- suppression du nouvel action set SteamVR haute priorite de la v3.3, qui pouvait monopoliser la main gauche ;
- Y revient dans l'action set principal via /actions/main/in/OrdersMenu ;
- le relachement de Y est surveille meme quand le menu radial est affiche ;
- si SteamVR masque le relachement, l'etat physique Oculus Touch de Y sert de secours ;
- seul le binding ResetPosition du clic du stick gauche est retire ; le binding Walk du meme stick est conserve ;
- aucun binding du controleur droit n'est remplace par ce patch.

Installation :
1. Fermer Left 4 Dead 2 et SteamVR.
2. Lancer INSTALL_Y_VOCALIZER_SD805.bat.
3. Redemarrer SteamVR.
4. Lancer L4D2VR.

Le programme sauvegarde le d3d9.dll, le manifeste SteamVR et le binding Oculus
avant installation dans :
VR\Wokgui_Y_Vocalizer_Backup_sd805_v3

Desinstallation :
Fermer le jeu et SteamVR puis lancer UNINSTALL_Y_VOCALIZER_SD805.bat.

Compilation : GitHub Actions, Release x86, MSVC v143. MinHook est reconstruit
avec le meme compilateur que le DLL.
